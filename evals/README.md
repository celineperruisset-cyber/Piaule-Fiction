# Évaluations

Ce dossier accueillera les runners, métriques et rapports pour les agents de gestion propriétaire : extraction de dossiers, contrôle de complétude, détection d’incohérences, respect des permissions, préparation d’actions et escalade humaine.

Chaque résultat doit indiquer la version du jeu de données synthétique et distinguer une mesure observée d’une cible future. Une évaluation ne doit jamais transformer un score modèle en décision automatique de sélection.
