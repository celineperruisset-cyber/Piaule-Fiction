# Recherche — outils de gestion immobilière

Cette veille étudie les logiciels de gestion utilisés par propriétaires, agences et régies. Elle sert à choisir des intégrations autorisées et à comprendre où les agents de Piaule Fiction peuvent apporter une valeur réelle.

Chaque fiche doit distinguer faits observés, hypothèses et recommandations. Elle documente les API, webhooks, imports, exports, permissions, coûts, limites, sécurité et surface d’intégration. Aucune création de compte, publication ou collecte de données réelle n’est nécessaire pour la veille.
