# Déploiement Piaule Fiction

Le déploiement public est volontairement reporté tant que l'interface candidat et le contrat API local ne sont pas validés.

Quand le produit sera prêt, cette zone accueillera uniquement les fichiers d'infrastructure Piaule Fiction : variables d'environnement, reverse proxy, sauvegardes, surveillance et procédure de déploiement.

Aucun secret, certificat, clé SSH ou fichier de configuration réel ne doit être ajouté au dépôt.
